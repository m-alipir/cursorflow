# Cursorflow

An ultra-smooth, customizable cursor motion blur & trailing effects tool for Windows.


## Features

- **Primary Cursor Integration:** Native Windows cursor responsiveness without input lag.
- **Smooth Secondary Trail:** A fluid, physics-based trailing cursor that follows your movement smoothly.
- **Asset Preservation:** Automatically mirrors your active Windows cursor scheme and custom assets.
- **Highly Customizable:** Adjust trail inertia, delay, opacity, and blur intensity.

## Installation

1. Download the latest release from the [Releases](../../releases) page.
2. Run `SmoothCursorOverlay.exe`.
3. Configure your trail preferences in the system tray icon settings.

## Configuration Options

<img width="442" height="859" alt="SmoothCursorOverlaySettings_wcEJUTaboX" src="https://github.com/user-attachments/assets/d408e9a8-156d-4e9d-97b3-ea8e07bbb28a" />

| Option | Description | Default |
| :--- | :--- | :--- |
| **Trail Delay** | Smoothness factor for the secondary cursor | `15ms` |
| **Opacity** | Transparency level of the trail | `70%` |
| **Scale Decay** | Shrink effect on motion stop | `Disabled` |
